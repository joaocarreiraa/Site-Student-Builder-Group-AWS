## 🚀 Sobre o Projeto

Este repositório abriga o código-fonte do **site oficial do AWS Student Builder Group (SBG) do IFPA Campus Belém**. O portal foi desenvolvido para centralizar informações sobre a comunidade, divulgar eventos, apresentar a equipe de liderança, exibir galerias de fotos de meetups e oficinas, além de conectar estudantes ao universo da computação em nuvem.

---

## 🎨 Identidade Visual & Tecnologias

O site foi construído seguindo uma identidade visual tecnológica e limpa, inspirada nos padrões da AWS:
* **Fundo Grafite Escuro (`#0b0f19`)** com padrão de grid tecnológico.
* **Azul Celeste / Azul Bebê (`#38bdf8`)** para destaques, botões e elementos interativos.
* **Tipografia Moderna:** Fontes *Space Grotesk* e *Inter*.
* **Tecnologias Utilizadas:**
  * HTML5 Semântico
  * Tailwind CSS (via CDN)
  * JavaScript Vanilla (para os carrosséis de fotos independentes)
  * FontAwesome (ícones)
